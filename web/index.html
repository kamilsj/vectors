Question format and limits

Load a JSON array with up to 10,000 questions, within 5 MiB. Each run samples up to 100 questions. A match requires the expected source and any supplied text in the same passage.

[
  {
    "question": "What is the retention period?",
    "expected_source": "policy.pdf#page=2",
    "expected_text": "30 days"
  }
]

expected_source is an exact source match; expected_text is optional. Generated PDF datasets can instead use expected_file, expected_page, and expected_text. File/page matching accepts folder prefixes; use an exact source to distinguish same-named files.
